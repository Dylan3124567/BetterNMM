# BetterNMM Program Info

Application name, logo and Windows resource templates for BetterNMM.

The logo (`io.github.betternmm.BetterNMM.svg`, also the `launcher` theme icon) shows mods stacked into separate
instances. `betternmm.ico` is rendered from it at 16 to 256 pixels. The logo is available under the CC BY-SA 4.0 license
in [LICENSE](LICENSE).
